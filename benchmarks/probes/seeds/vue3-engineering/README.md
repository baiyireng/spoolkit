# 新项目：后台管理前端（只要工程骨架）

后端接口还没定，这一轮**不写业务**，先把前端工程立起来——页面用示例内容占位就行。

## 固定的技术栈

- Vue 3 + TypeScript + Vite
- 路由：Vue Router
- 状态：Pinia

## 这一轮要看的是「工程化那一层」

目录要分层（页面、组件、路由、状态、接口、组合式函数、工具、样式各归各位，
不要全堆在 `src/` 下面），并且现代前端工程该有的东西都要在：

- 路径别名（`@` → `src`）
- TypeScript 严格模式
- 环境变量（要有示例文件，变量要能在代码里有类型）
- 代码检查 + 格式化配置
- 单元测试
- 构建与开发脚本
- CI（装依赖之后跑检查 / 测试 / 构建）

## 约束

- **依赖先别装**（我这边网络不方便），也**不要跑构建**：把文件和配置写对就行，
  我回头自己 `install`。所以不用生成锁文件。
- 规模控制住：两三个示例页面、一两个示例组件、一个示例 store、一个示例请求层就够。
- 不要引入 UI 组件库、不要编造后端接口文档。
