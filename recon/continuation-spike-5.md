# 尾部怎么交给模型

状态：L0.7 完成。不改生产代码，不进入 L3.1。

## 固定条件

| 项 | 值 |
|----|----|
| 模型 | 本机 llama-server，`Qwen3.8-27B-UD-IQ2_S`，`n_ctx=8192` |
| 采样 | `temperature=0`，`seed=1`。同一策略的三次 repeat 正文相同 |
| 思考 | `enable_thinking=false` |
| 文章 | 技术说明、项目复盘、方案对比。初稿沿用 L0.6 裁好的半句 |
| 状态 | 五种策略都保留 D4：已完成节、当前节、未开始标题 |
| 续写 | A–E 各 3 次。最多 3 轮，每轮申请 `max_tokens=1500`。当前节收束后，下一轮不再附尾部 |
| 预算 | `OfflineTokenCounter`。判定线是 `prompt + max_tokens <= 8000` |
| 样本 | 3 篇初稿 + 114 次新的续写请求 |

脚本和记录在 `recon/continuation-spike-5/`。日志里没有密钥。初稿没有重新生成。

尾部交付：

| 策略 | 交给模型的尾部 |
|------|----------------|
| A | 当前节最后 280 字，单独一条 assistant，后面再跟 user 指令 |
| B | 当前节最后一个完整句，最多 120 字，作为 assistant |
| C | 当前节最后一段放在 user 里，前面写「以下只是已写结尾，仅作定位，不要照抄」 |
| D | 不交尾部。给当前节标题、要点、上一节 80 字摘要，要求重写整节 |
| E | 当前节最后 80 字作为 assistant，user 要求只从最后一个字之后继续 |

D 的拼接是用新正文换掉当前节。其余策略把续写接在初稿后面。

## 完成判据

真完成要同时满足：

- 当前节最后一行是「。」「！」「？」。
- 全文每一节的最后一行都是完整句。半句残留按没收住的节数计。
- 「完」只允许出现在大纲最后一节里。出现在这节标题之前，记一次提前。
- 每个未开始标题去掉大纲要点后不少于 80 字，并且该节自己收成完整句。
- 全文不少于 3000 字。
- 续写对初稿的 12 字重叠低于 0.5。

「完」不能单独算完成。可读性仍是同一个人按 L0.3 的尺子打的，不是盲评。

脚本自检覆盖了：补完半句并写满后节才算真完成；中间写「完」不算；把初稿尾部贴三遍时重叠不低于 0.5；D 的替换会拿掉半句。2000 个「甲」仍按 2000 token 计。

另外核对了初稿最后 12 个字还在不在。判据里的「当前节收尾」只看该节最后一行。半句原文还在，表示这一行没有被接上，后面另起了一段。

## 每种尾部的行为

- A：280 字放到 assistant 之后，方案对比没有再出现 L0.6 那种 0.961 重叠。三篇都把半句原文留着。技术说明和方案对比另起一个「## 当前节」重写，项目复盘把当前节收成完整段，然后只留下「结果、原因、改法、下一步」四个空标题和「完」。
- B：九次都让当前节的最后一行变成完整句，重叠低于 0.02。半句原文九次都还在，模型是在半句后面另起一段。技术说明因此过了真完成；项目复盘收完当前节后同样只交空标题；方案对比写完后面几节，又把已完成的「问题」按大纲抄了回来，这一节没有句号。
- C：带边界的用户引用没有挡住重写。技术说明仍从「## 余量」重开，最后「做法」连写三次「第一步，定 n_ctx。看」。项目复盘重开「过程」。方案对比是五组里这一篇最好的一次：半句后面接上「第二个优点是增量。续写只关心……」，六节最后一行都收住了，全文 2717 字，差在 3000 字下限。
- D：三篇的半句原文都被换掉。技术说明重写出完整的「余量」并写完后三节。项目复盘三轮只在「## 目标 / 要点」和「## 过程 / 要点」之间来回贴，重叠 0.542。方案对比重写了「续写」，末尾仍把「问题」按大纲抄回。
- E：九次都从最后 80 字往下接，没有整段复读。方案对比把「增量」收成「第二个优点是增量成本。」项目复盘下一行以逗号接上半句，然后写了「完」，再留下四个空标题。技术说明半句后的新句是「2800 + 4000 = 6800 token……」，全文 4004 字，六节都收住。

## 预算

114 次续写全部满足 `prompt_tokens + max_tokens <= 8000`。最大合计是 1917。`OfflineTokenCounter` 比服务端 prompt 多 36 到 174 token，平均多 66，没有一次估小。

这 114 次合计 70962 token，耗时 1241 秒。

没有改产品代码，没有重跑 pytest。

## 决策

真完成率最高、并且没有整段复读的是 B 和 E，都是 3/9，而且都只发生在技术说明。D 也是 3/9，但项目复盘在整段复读大纲，不能算赢。C 和 A 是 0/9。

按决策门，L3 的当前节要用短尾，不用整节重写，也不用 280 字。B 是最后一个完整句，E 是最后 80 字并要求从最后一个字之后继续。E 会把半句接下去；B 会把半句留在段中、另起一段。短尾优先用 E 这种接法。

三篇没有被同一种策略写完。项目复盘在收住当前节之后会交空标题，或者在重写时复读大纲。方案对比会在末尾把已经写过的第一节再抄回来，全文也没有到 3000 字。先改状态和提示，不进入 L3.1。
